## Architecture decisions

- i18n without a library: `app/[lang]` routes + typed dictionaries + middleware redirect
  (official Next.js pattern). English is the default locale; ES via a toggle.
- Contact = WhatsApp (`wa.me`) + `mailto:` only. No form, no email service.
- TanStack Query / Zustand not installed: no server state or cross-component client state.
- `cn` package (by shadcn, repo shadcn-ui/cn) is used instead of clsx + tailwind-merge;
  generated by shadcn CLI 4.x.
- Locale choice from the EN/ES toggle is stored in the `NEXT_LOCALE` cookie; the middleware
  uses it for locale-less URLs, otherwise redirects to /en.
- Spanish copy uses neutral "tú" (not voseo) to reach clients across LatAm/Spain.
- Theme: next-themes (class strategy, system default). Brand tokens `--brand` (indigo) and
  `--brand-2` (cyan) + `text-gradient` utility in globals.css.
- lucide-react 1.x has no brand icons (GitHub/LinkedIn): use text labels + generic icons.
- Unknown paths under /en|/es hit `app/[lang]/[...rest]` → localized not-found.
- Landing sections live in `src/features/landing/components/`; non-translatable data (icons,
  tool names) in `src/features/landing/data.ts`; all copy in the dictionaries.
- Profile photo = GitHub avatar via next/image (`images.remotePatterns` in next.config.ts).
- Hero chat demo is a client component; respects prefers-reduced-motion (static).
- Don't run `pnpm build` while `pnpm dev` is running: both write to `.next/` and the dev
  server starts failing with ENOENT manifest errors (restart dev to recover).
- Prefilled contact copy lives in the dictionaries (`contact.whatsappMessage`, `emailSubject`,
  `packages.whatsappMessage` with a `{package}` placeholder). Package CTAs open WhatsApp directly.
- Floating WhatsApp button only below `lg` (desktop has the header CTA).
- SEO helpers in `src/lib/seo.ts` (metadataBase from NEXT_PUBLIC_SITE_URL, hreflang map).
  All absolute URLs (canonical, OG, sitemap, robots, JSON-LD) depend on that env var.
- OG image generated per locale at build time (`app/[lang]/opengraph-image.tsx`); X falls back
  to it automatically (Next emits twitter:image). Favicon/apple icon generated from code
  (`app/icon.tsx`, `app/apple-icon.tsx`); middleware matcher excludes `icon|apple-icon`.
- JSON-LD (Person + ProfessionalService) in `features/landing/components/json-ld.tsx`.
- pnpm pinned via `packageManager` (pnpm 12 writes it into the lockfile); Vercel needs
  `ENABLE_EXPERIMENTAL_COREPACK=1` to use it. Node pinned with `engines.node: 24.x`.
- CI uses placeholder NEXT_PUBLIC_* values; real values only in Vercel / .env.local.
- `next build` without Turbopack for production stability; `next dev --turbopack` in dev.
