## Stack deviations

- 2026-09-27: No backend (NestJS/Mongo not used). A static landing with WhatsApp and
  mailto links needs no server. Not an optional-module addition, so no ADR.
- 2026-09-27: Next.js pinned to 15.5.x although 16 is `latest`, to follow the default stack.

## Architecture decisions

- i18n without a library: `app/[lang]` routes + typed dictionaries + middleware redirect
  (official Next.js pattern). English is the default locale; ES via a toggle.
- Contact = WhatsApp (`wa.me`) + `mailto:` only. No form, no email service.
- TanStack Query / Zustand not installed: no server state or cross-component client state.
- `cn` package (by shadcn, repo shadcn-ui/cn) is used instead of clsx + tailwind-merge;
  generated by shadcn CLI 4.x.
- `next build` without Turbopack for production stability; `next dev --turbopack` in dev.
